Setup: dictate, sort, execute

One note a day on the phone, one command on the Mac, and every line becomes a calendar entry, a reminder, or a Claude Code session that works while you do something else. Everything here is open: copy one script, paste it in a terminal, and you have the same setup in about ten minutes.

Apple Notes (dictated)→cc inbox classifies→Calendar · Reminders·Claude Code sessions (tmux)→ledger → cockpit → weekly memo

What you get

CommandWhat it does
ccpick a project, open (or re-attach) its Claude Code session; cc <name> -c resumes the last conversation
cc inboxreads today's Apple Note, classifies each line (task / event / reminder, with a priority), shows the plan, then dispatches: events to Calendar, reminders to Reminders, tasks to their own session. --auto runs tasks detached and autonomously
cc run · cc cockpitlaunch every open task through a background queue; one page with tasks by priority, what's waiting on you, running sessions, today's log
cc memo · --messagecompiles the week's work (session ledger, project logs, git) into a memo draft, then into a short message with named asks and deadlines
cc commsa bank of drafted messages pushed into a Reminders list, editable and copyable from the phone
Right-click → ServicesAccentuer fixes French accents in any selected text (for a US keyboard); Launch idea turns a selected Note line into a session

Each project folder carries a CLAUDE.md (what the project is, where raw data lives, the rules), so a session never needs the context explained twice. Raw data is treated as read-only everywhere.

Install in three steps

1

Claude Code on the Mac

You need a Claude account (Pro or Max), the Claude desktop app, and Claude Code. The clearest walkthrough for non-developers is Chris Blattman's Install Claude Code (Mac); the short version:

curl -fsSL https://claude.ai/install.sh | bash
claude        # sign in once, then type anything to check it answers

Homebrew is needed for tmux and fzf: brew.sh, one command to paste.

2

The kit, in one paste

The script below contains every file of the kit (22 files, all plain text, nothing downloaded from anywhere). It writes them to ~/claude-kit and runs the installer: launcher, scripts, Quick Actions, tmux config, a scratch folder with a project template, and one line in your .zshrc. Read it first if you like; that is the point of shipping it as text.

  or download it (.zsh, 80 KB)

Then in Terminal: paste, press Enter. Or, to run it straight from the clipboard:

pbpaste | zsh
3

First run

cc ls                 # should show: scratch
cc new first-idea     # a project with its CLAUDE.md, Claude opens on it

Create a note titled to dos <today's date> in Apple Notes with three lines: a meeting (“call X Thursday 3pm”), a reminder (“send the file to Y tomorrow”), a piece of work (“write a one-page summary of …”). Then cc inbox. macOS will ask once to let Terminal control Notes, Calendar and Reminders.

For each existing work folder: cd into it, cc add, then in the session ask Claude to write the project's CLAUDE.md. From then on cc <name> opens it with its context.

The daily loop

WhenWhat
Anytime, phoneDictate into today's note (Siri: “note: …”). Lines, not paragraphs: a verb, the input, the output.
Morning, Maccc inbox --auto. Events and reminders land; tasks start as detached sessions. cc cockpit to see the board.
Through the daycc to jump into a session; Option+←/→ between them; Ctrl-b d to leave everything running.
Weeklycc memo, dictate what the sessions can't know, cc memo --message, send.

What it is not

It does not send anything. Messages and emails are drafts you copy and send yourself; sessions write files, never post. It does not touch raw data. It does not share anything across machines: the state lives in ~/scratch and ~/.config/claude-launcher on your Mac. And it is a set of plain zsh and Python files you can read in an afternoon, which is why it is shared this way rather than as an app.
